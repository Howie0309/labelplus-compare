# labelplus 对比截图与评估

把 labelplus「评估任务 query 查看」页里多个环境（如 线上 vs 策略-genui-联调）的回答逐轮截图并排，做单条 / 批量模型对比评估、人工 GSB 标注，导出 Excel 或 JSONL。

## 需要什么

- macOS（启动脚本按 macOS 写；其它系统可用 `npm start`）
- [Google Chrome](https://www.google.com/chrome/)：无头渲染截图，以及登录 labelplus
- [Node.js 20+](https://nodejs.org/zh-cn)：没有的话 `brew install node`
- 能访问公司内网的 labelplus 账号
- 可选：一个 OpenAI 兼容、支持图片输入的模型接口（只截图不需要）

## 安装与启动

```bash
git clone https://github.com/Howie0309/labelplus-compare.git
cd labelplus-compare
```

然后在访达里**双击 `启动.command`**。首次会自动安装依赖，完成后浏览器打开 http://127.0.0.1:3230 。关闭终端窗口即停止。

> 首次双击如果提示「无法打开，因为来自身份不明的开发者」：右键 `启动.command` → 打开 → 再点一次「打开」。
> 也可以在终端运行 `npm install && npm start`。

更新到最新版：在目录里 `git pull`，再双击启动。

## 使用

1. **登录**：右上角「更新 Cookie」→「打开 Chrome 登录」。会弹出一个专用 Chrome 窗口，按平时方式登录 labelplus，成功后窗口自动关闭、Cookie 自动保存。之后 Cookie 过期会先在后台自动续期，续不上才提示重新登录。也可以手动粘贴 DevTools 里 Copy as cURL 的整段命令。
2. **新建批次**：粘贴评估页链接 → 解析 → 勾选并排序环境（第一个为 A，一般选基线「线上」）→ 选范围（仅这一条 / 前 N 条 / 剩余全部）→ 创建并开始截图。工具会顺着「下一条」自动拉取对话，每轮生成一张卡片，多环境时另存一张左右拼图。
3. **对比查看**：点卡片，左侧各环境并排同步滚动（可切「拼图」），右侧看上文、人工标注（`1` A 更好 / `2` 持平 / `3` B 更好）、`E` 单条模型评估、复制或下载拼图，`←` `→` 切换。
4. **批量评估**：在「设置」里填模型接口后，工具栏点「批量评估待评估」；「整体分析」汇总胜率和典型问题。
5. **导出**：
   - **Excel**：每轮一行，`query`、`上文`、`截图_<环境名>` 各一列，图片锚定在本行单元格内，可直接交给按 Excel 读图的评估脚本或平台（如「评估工作台 · 自动评估」，Prompt 里写 `{{query}}`、`{{上文}}` 并勾选截图列）。
   - **JSONL**：每轮一行，含各环境截图的本机绝对路径、模型与人工结果，给自己的脚本用。

## 模型评估说明

默认 Prompt：多环境按 需求满足 / 信息质量 / 结构与可读性 / 富媒体与组件 / 交互与引导 5 个维度给 A、B 各打 1–5 分并给出偏好（A / B / same）；单环境按维度打分。可在设置里改 Prompt，只要输出同样的 JSON 字段，就能自动统计胜率和总分（各维度平均 × 2，10 分制）。

## 数据都在本机

| 内容 | 位置 |
| --- | --- |
| 批次、截图、评估与标注 | `batches/<id>/` |
| 模型 API Key、Cookie、Prompt、并发设置 | `config.json`（权限 600） |
| 专用 Chrome 的登录资料（用于自动续期） | `.chrome-profile/` |

以上都在 `.gitignore` 里，不会被提交。服务默认只监听本机 `127.0.0.1`。

## 多人一起标注（局域网）

1. 发起人：「设置 → 多人协作」勾选开启，复制分享链接发给同事（同一内网）。macOS 首次会问「是否允许 node 接受传入连接」，点允许。
2. 同事：浏览器打开链接，输入自己的名字即可标注，不用安装任何东西。
3. 同事只能查看、人工打分 / 备注、导出；截图、模型评估、设置只有发起人能操作（用的是发起人的 Cookie 和模型额度）。
4. 同一条多人标注时后改的覆盖先改的，页面显示「最后由谁修改」；别人改的几秒内同步到自己页面，顶栏显示谁在线。可按「我标注的 / 别人标注的」筛选。
5. 发起人电脑需保持开机、服务不退出。「重新生成链接」会让旧链接立即失效；关闭协作后同事无法再访问。
