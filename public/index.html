自动获取（推荐）

会弹出一个专用 Chrome 窗口打开 labelplus，按平时方式登录即可，登录成功后窗口自动关闭、Cookie 自动保存。之后 Cookie 过期会先自动续期，续不上才需要再登录一次。

或手动粘贴
  1. 浏览器打开任意 labelplus 页面，按 F12 打开 DevTools → Network
  2. 点任意一个 labelplusapi 请求 → 右键 → Copy → Copy as cURL
  3. 整段粘到下面（只粘 Cookie 那一串也行）。

设置

VLM（OpenAI 兼容接口，需支持图片输入）

只写评估角色、维度、标准和输出格式。问题、上文、各环境截图由程序放进 user 消息，多环境依次标为 A、B。输出 JSON 用 dimensions[{name,a,b,reason}] + preference（A / B / same），可自动拆分数和统计胜率。页面与导出里的展示顺序由程序固定为「偏好 → 结论 → 问题 → 意图 → 维度明细」，与 JSON 字段顺序无关。

输出 JSON 用 dimensions[{name,score,reason}]，总分 = 各维度平均 × 2（10 分制）。

评估结果字段

页面按模型输出的 JSON 原样展示（字段顺序跟 Prompt 走，不用改工具）。下面几个字段参与统计、筛选和导出，填 Prompt 里对应的字段名；留空用默认。改完保存后，已有评估会按新设置重新排版，不会重新调用模型。

多人协作（局域网）

同事只能查看、人工标注和导出；截图、模型评估、设置只有你能操作（用的是你的 Cookie 和模型额度）。同一条多人标注时后改的覆盖先改的，并记录修改人。你的电脑需要保持开机、服务不退出。首次开启 macOS 可能弹出「是否允许 node 接受传入连接」，请点允许。
